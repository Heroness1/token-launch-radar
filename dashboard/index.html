Farm assumptions — one table, everything the verdicts rest on

Assumptions, not snapshot facts. Change the deposit, drop share or T-bill rate and every verdict and net on this page moves. The board file is written at the defaults, so the default view always agrees with it.

Method: value = TVL × exp(fitted log multiple), Huber fit on launched tokens with market cap ≥ $1M. Ranges from leave-one-out residuals; rank ranges from a 200-refit bootstrap.
