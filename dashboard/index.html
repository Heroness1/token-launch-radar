Pre-token protocols, ranked by what their token would be worth if it launches. Fitted on the protocols whose tokens already trade — no hardcoded names.

Coverage ledger — every protocol in the snapshot, exactly once

A protocol is “already tokened” when any of its token fields (gecko id, symbol, market cap) says so. The snapshot’s fields disagree for 272 protocols — a gecko id and symbol, but no market cap — and those count as tokened, the conservative reading. “Records no token” is a record, never proof a protocol has none.

Method: implied value = TVL × exp(fitted log multiple). The multiple is fit by OLS on the already-tokened protocols (intercept, size, 7-day growth, age) plus a category effect that only counts with ≥3 launched peers. Ranges come from a 200-refit bootstrap. Farm economics use the parameter table above. A protocol “records no token” when DefiLlama carries no symbol, gecko id or market cap for it — that is a record, not proof. Nothing here is financial advice, and no token is guaranteed.
