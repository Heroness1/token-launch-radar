How the value is worked out

Implied value = TVL × the median market-cap-to-TVL ratio of launched protocols in the same category. Ratios are winsorized to the 5th/90th percentile of all launched ratios, then shrunk toward the global median when a category has few launched peers, so one odd peer cannot set a whole category. The result is adjusted by 7-day TVL growth (±30% growth moves value by up to ±12%) and by age (a protocol that has run up to 4 years with no token gets up to 8% more than a brand-new one). Low/high use the category’s 25th/75th percentile ratio. Nothing is hardcoded by name: the ranking follows from the snapshot’s own figures.

“Records no token” is not “has no token.” A protocol is on this board when DefiLlama’s record carries no symbol, gecko id or market cap for it. It may still have a token the record does not carry. Wrapped, staked and bridged products of tokens that already trade, and exchanges, are left out. Gas costs in the farm plans are rough per-transaction estimates for the chain, not quotes. This is research, not financial advice, and it never predicts whether or when a token launches.
